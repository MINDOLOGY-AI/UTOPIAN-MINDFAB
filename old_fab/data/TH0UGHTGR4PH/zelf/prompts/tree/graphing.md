Graphing Style Guide:  

0: the wording in nodes must be concise. for fast reading.  


1: make sure the placements reflect logic! within a folder the stuff that are unrelated should be placed vertically. stuff that build on each other should be horizontal left to right. use functional nodes like support and reject etc to connect them.  
each Obj should be ONE and ONLY ONE idea.  

the goal is we can see the argument visually. in contrast to say just a single big doc where we can't tell whether anything is every true. or just a bunch of stuff listed horizontally in a folder that completely misses the point of the graph.  

2: ALL THEORIES must be supported somehow. by Axioms, Definitions, previous Theories, or Evidence.   

3: try to keep things compact. a single node off to the far end that makes the whole folder bigger is absolutely unacceptable.
